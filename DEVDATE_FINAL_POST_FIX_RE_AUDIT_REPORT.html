4. Pre-Launch Operations Guide

1. Render Production Environment

Configure the following in Render Dashboard:

  • NODE_ENV=production
  • MONGO_URI=<Your-Atlas-Connection-String>
  • JWT_SECRET=<Cryptographic-Secret>
  • REFRESH_TOKEN_SECRET=<Secure-Secret>
  • BREVO_API_KEY=<Your-Brevo-API-Key>
  • ALLOWED_ORIGINS=https://your-domain.com

2. GitHub Keep-Alive Secret

Configure repository secret for 14-min pings:

  • Navigate to: Repo Settings > Secrets > Actions
  • Secret Name: KEEP_ALIVE_URL
  • Secret Value: https://<render-app>.onrender.com/health

3. Mobile Release Build

Set EXPO_PUBLIC_API_URL=https://<render-app>.onrender.com/api before running eas build.
