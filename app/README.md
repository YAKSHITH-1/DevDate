# DevDate

A React Native with Expo app for developer project collaboration.

## Project Structure
- `/app` - Main React Native Expo project
- `/app/assets` - Images, icons, and other assets
- `/app/components` - Reusable UI components
- `/app/screens` - Screen components
- `/app/styles` - Stylesheets and theme files

## Development
To run the app:
1. Install dependencies: `npm install`
2. Start the development server: `npm start`
3. Run on Android/iOS/Web as needed

## Design Implementation
This app implements the exact design from the provided screenshot, matching:
